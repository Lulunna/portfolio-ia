Aplicação web funcional para organização de tarefas, focada em manipulação de elementos na tela e ajustes manuais de interface.

## 🛠️ Como trabalhei (O Diferencial)
* **Engenharia de Prompts (Claude):** Utilizei o Claude para acelerar o desenvolvimento, gerando a estrutura inicial e a lógica base dos projetos.
* **Código na Mão (Ajuste Fino):** Atuei diretamente no código para corrigir bugs de lógica que a IA não resolveu, refatorar funções em JavaScript e customizar toda a estilização em CSS.
* **Versionamento e Deploy (Git):** Realizei todo o controle de versão e o envio dos códigos utilizando comandos Git diretamente pelo terminal.
* **Integração e Validação:** Analisei criticamente o código gerado pelo modelo, garantindo boas práticas, fluidez e o funcionamento correto de ponta a ponta.
